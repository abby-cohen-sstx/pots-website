## Step 1: Write in Obsidian
- Use headings ## through ####
- Use plain markdown links
- Either type components directly in Obsidian, or add placeholders and replace later

## Step 2: Move to MDX
- Pick a kebab-case-filename unique to the article
- Format frontmatter (see above)
- Fix any components if necessary
- Add article ID to src/globals/articleOrder.ts (or don't; the article will sort to the end)
- Move any images to src/images/articles/

## Step 3: Build to Validate
- Run npm run build to validate (don't rely on run dev only)

#### Accordion Lists
You can also create an accordian list where opening one item closes all others by adding a `group` property:
<Toggle summary="Accordion item one" group="group a">
Accordion 1 contents
</Toggle>

<Toggle summary="Accordion item two" group="group a">
Accordion 2 contents
</Toggle>

<Toggle group="group a">
<span slot="summary">Accordion item 3 with **rich text** and citations.<Cite ids="lauPosturalOrthostaticTachycardia2026" /></span>

Accordion 3 contents
</Toggle>

### Callouts
`type` must match one of the options in `components/inlineContent/callout-variants.ts`.
`title` is an optional property which overrides the default title.

<Callout type="tip">
Default tip-type callout
</Callout>

<Callout type="warning">
Default warning-type callout
</Callout>

<Callout type="warning" title="Custom title">
Warning-type callout with custom title
</Callout>

### Figures
- `src` must point to an image in `src/images/articles/`
- Use `alt` for alt text (required; use "" for purely decorational images)
- `width` can be set to `full` or `partial.` Defaults to `full`
- The caption is optional and goes in the component **body** (not a prop), so it can include **rich text** and citations
